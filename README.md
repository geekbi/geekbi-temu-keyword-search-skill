# 极鲸云 Temu 关键词搜索 Skill

通过极鲸云提供的真实 Temu 关键词数据，查询特定关键词、热销词、蓝海词和新词，分析关键词对应的需求规模、销量与销售额趋势、商品和店铺供给、竞争强度、平均价格与市场阶段，帮助国内跨境卖家识别值得关注的市场需求和关键词方向。

## 主要能力

| 能力 | 可以解决的问题 |
| --- | --- |
| Temu 关键词搜索 | 查询特定关键词及其关联类目、需求规模、平均价格、商品数、店铺数和市场时间，快速了解关键词对应的市场概况 |
| 热销词与趋势词发现 | 按总销量、近期销量或销售额增长筛选关键词，识别需求规模较大或近期增长较快的市场方向 |
| 蓝海词与新词研究 | 结合蓝海指数、需求规模、供给数量、增长趋势和市场时间，发现值得继续验证的关键词信号 |
| 供需与竞争分析 | 对比销量、销售额、商品数和店铺数及其变化，判断关键词需求增长是否快于供给增长 |
| 价格与市场阶段分析 | 结合平均价格、最早商品上架时间、关联类目和半托管渗透情况，判断关键词所处的价格与市场阶段 |

## 适用场景

本项目适合以下任务：

- 查询某个 Temu 关键词的需求规模、平均价格和竞争情况。
- 查找 Temu 热销词、蓝海词、新词和近期增长词。
- 分析关键词日、周、月销量及销售额趋势。
- 对比关键词下的商品供给、店铺供给及其变化。
- 研究某个类目范围内的关键词需求和市场结构。
- 判断关键词对应市场处于新兴、增长、成熟还是短期波动阶段。
- 为市场定位、关键词布局和后续调研筛选优先方向。
