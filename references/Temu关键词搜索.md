# Temu 关键词搜索

## 工作原则

- 只使用极鲸云返回的真实关键词数据，不编造关键词、翻译、指标或查询结果。
- 明确区分数据事实、可复算的派生指标和分析判断。
- 默认使用简体中文，日期使用绝对日期；平均价格和销售额标明当前 Temu 站点币种。
- 对缺失值、异常值、样本量和未完成分页作显式说明；指标为 `0` 时结合其他指标和更新时间核验，不自动当成真实为零。
- 接口参数、响应字段、请求命令和原始 JSON 仅用于内部调用。进度说明、分析过程和最终答复使用中文业务名称，不展示英文参数；只有用户明确要求开发对接或故障排查时才展示必要技术信息。

## 执行流程

1. 明确用户是查特定关键词、找热销/蓝海/新词、从品类中找词，还是研究关键词市场机会。
2. 明确站点、关键词或类目范围、市场时间、需求规模和供给规模等必要条件。未指定站点时默认美国站，并在结果口径中说明。
3. 读取 [Temu 关键词搜索接口](Temu关键词搜索接口.md)，生成最小必要查询条件。用户要求热销词、蓝海词或最近新词时，再读取 [Temu 关键词榜单预设](Temu关键词榜单预设.md)。
4. 未指定站点或明确要求美国站时直接使用默认值；只有用户指定其他国家或地区时，才运行 `scripts/temu_site_list.py` 实时解析站点。
5. 使用 `scripts/temu_keyword_search.py` 查询；服务端要求暂停查询时，按 [查询暂停与恢复流程](查询暂停与恢复流程.md) 提示并暂停。
6. 恢复条件满足后原样重跑查询，取得关键词数据后再分析。
7. 查询失败时，只向用户提示错误输出一级 `msg` 的中文文案，不展示错误 JSON、状态码、异常栈或内部字段。
8. 核对分页范围、样本量、关键指标和更新时间后再分析；未读取全部分页时明确标为样本。

## 查询策略

- 关键词条件同时匹配英文关键词和中文关键词。查特定词时优先使用关键词，不自行翻译后替换用户输入。
- 仅使用用户提供或当前上下文中已有可靠来源的一级或二级类目 ID，不根据类目名称猜测 ID。没有可信类目 ID 但已有关键词时，直接按用户原始关键词查询；必须严格限定类目时请用户提供类目 ID。
- 查特定词时一般使用关键词条件；做品类词机会挖掘时一般使用类目条件。只有用户明确要在某品类内查特定词时才组合，并说明组合条件可能减少结果。
- “市场年龄”使用该关键词下最早商品上架时间作为代理指标，不是关键词的创建时间。日期越新，表示该词对应市场可能更新。
- 未指定排序时按问题选择一个主指标：热销优先总销量，蓝海优先蓝海指数，新词优先最早商品上架时间，近期增长优先月销量增长率或月销售额增长率。
- 服务端为每个关键词返回 `linkUrl`，指向该关键词在极鲸云的 Temu 关键词详情页。每个被展示的关键词都必须把关键词名称写成 `[关键词](<linkUrl>)`；这条规则适用于表格、列表、排名、候选清单和正文，不因用户未主动要求链接或要求简洁结果而省略。

## 分析方法

- 需求规模：结合总销量、总销售额和日/周/月销量与销售额，不仅凭单一累计指标判断。
- 增长趋势：结合日、周、月增长率识别加速、回落或短期异常，单个时间窗口不足以证明长期趋势。
- 竞争供给：结合商品数、店铺数及其变化量和增长率，识别需求增长但供给尚未同步涌入的词。
- 蓝海指数：数值越高越值得优先验证；在完整计算口径不明时，只将它作为供需综合指标，与需求、供给和增长交叉验证。
- 价格带：平均价格使用当前站点币种，可用于初步判断该词对应的价格带，但均值不代表商品价格分布。
- 市场阶段：结合市场年龄、需求增长和供给增长，区分“新出现且加速”、“成熟稳定”和“短期异常”，不把日期较新直接等同于值得进入。
- 品类与托管模式：结合关联类目、半托管商品数和半托管店铺数，判断该词的主要市场归属和半托管渗透情况。
- 下一步验证：说明候选词仍需结合具体商品、成本、合规和供应链信息验证；本能力不编造尚未查询的数据。

## 输出要求

关键词表格或清单的名称列必须使用 `[关键词](<linkUrl>)`。发送答复前逐行检查：服务端返回非空 `linkUrl` 的每个关键词都必须存在对应的可点击关键词名称，缺少任何一个都先修复再交付。

用户只索要关键词链接时，仅返回 `[关键词](<linkUrl>)`，不附加接口、字段、链接类型或缺失状态说明。

默认按以下顺序输出：

1. 一句话结论：哪些关键词值得关注或继续验证。
2. 数据口径：站点、类目范围、时间条件、排序、分页范围、样本量和更新时间。
3. 候选关键词：展示英文词、中文词、关联类目、核心指标和入选原因。
4. 需求、趋势与竞争判断：区分事实、计算和判断。
5. 风险、数据限制和下一步验证动作。

用户只要关键词列表或简单搜索结果时保持简洁，不强行扩展为完整市场报告。
