# Temu 关键词榜单查询预设

根据用户的榜单或搜索词调研意图选择一个查询预设，并以用户明确提出的条件为准。

## 使用规则

- 每次只选择一个最贴近用户意图的主预设；除非用户明确要求，不叠加多个预设。
- 在预设之外补充站点、页码和每页数量，可按需增加关键词或类目。用户的明确条件优先于预设。
- 排序方向统一使用 `desc` 或 `asc`。
- 美国站使用默认值，其他国家或地区先实时查询站点列表。
- 预设只定义排序，不表示命中关键词必然值得使用；取得数据后仍需结合需求规模、近期增长、商品供给、店铺供给、市场时间和价格带验证。

以下参数块省略站点、分页及所有未设置条件。

## 查询预设

### 热销词

适用于“热销词”“销量最高的搜索词”“头部需求词”等请求。

```text
sort=totalSold
order=desc
```

该预设只按总销量从高到低排序，不自动补充类目、最低销量或时间窗口。

### 蓝海词

适用于“蓝海词”“供需关系更好的搜索词”“竞争相对小的词”等请求。

```text
sort=dsr
order=desc
```

该预设只按蓝海指数从高到低排序。蓝海指数不能单独证明该词值得使用；对排名靠前的词，至少检查总销量、月销量与增长率、商品数、店铺数和平均价格。

### 最近新词

适用于“最近新词”“新出现的市场词”“新趋势词”等请求。

```text
sort=firstOnSaleTime
order=desc
```

该预设按关键词下最早商品的上架时间从新到旧排序，不自动增加“近 1 个月”或“近 3 个月”的时间范围。该时间不是关键词创建时间，也不能单独证明是新趋势；还要检查月销量、月销量增长率和供给变化。

## 补充调研方法

- 找近期需求增长：按月销量增长率或月销售额增长率降序，并设置最低月销量或月销售额，避免小基数极端增长。
- 找需求增长快于供给的词：先筛选月销量增长率为正，再对比月商品数和月店铺数增长率；这一判断需在返回数据后计算，不是单一接口条件。
- 找品类词：已有可信的一级或二级类目 ID时可限定范围，再按用户的需求、增长或蓝海目标排序；没有可信 ID 时按用户原始关键词查询，不猜测类目 ID。

## 生成请求前检查

1. 是否只选择了一个主预设。
2. 美国站是否使用默认值，其他站点是否已实时解析。
3. 类目 ID 是否来自用户或当前上下文中的可靠来源，而不是根据名称猜测；没有可信 ID 时是否已省略类目条件。
4. 是否无依据叠加了时间、销量阈值或增长率条件。
5. 排序方向是否只使用 `asc` 或 `desc`。
6. 查询条件是否全部存在于关键词搜索契约中。
